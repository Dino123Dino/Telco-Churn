\# Telco Customer Churn Analysis



\## 📌 Project Overview

This project focuses on analyzing telecommunications customer data to identify the key drivers of customer churn. By leveraging SQL and data visualization, customer behavior, service usage, and contract types were analyzed to provide actionable insights for customer retention strategies.



\---



\## 🛠️ Tech Stack \& Tools

SQL (PostgreSQL): Data extraction, aggregation, window functions, and churn segmentation.

Power BI: Interactive dashboard design and visual KPI tracking.

GitHub: Version control and documentation.



\---



\## 📊 Key Features \& Analytical Workflow

1\. Data Cleaning \& Preparation: Handling missing values, standardizing data types, and setting up clean structures for reporting.

2\. Exploratory Data Analysis (EDA via SQL):

&#x09;- Calculating overall churn rate across demographical and service-based segments.

&#x09;- Evaluating the impact of contract terms (Month-to-Month vs. One/Two-Year contracts) on retention.

&#x09;- Analyzing payment methods and revenue metrics (Monthly Charges and Total Charges).

3\. Data Visualization: Executive dashboards displaying core KPIs (Total Customers, Active Subscribers, Churn Rate, and ARPU) with interactive slicers.



\---



\## 💡 Key Insights

Contract Type: Month-to-month subscribers account for the highest churn volume compared to long-term contract holders.

Add-On Services: Customers without tech support or online security features exhibit significantly higher cancellation rates.

Payment Methods: Electronic check users show a higher likelihood of churn compared to automated payment options.
